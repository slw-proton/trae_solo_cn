# 示例2：多 Agent 协作

## 概述
这个示例展示了如何让多个专业化的 Agent 协同工作来完成复杂的商业分析任务。

## 场景
对"AI驱动的智能家居设备"进行全面的市场分析，需要：
- 市场研究和竞争分析
- 技术可行性评估
- 财务建模和预测
- 综合报告生成

## 团队架构

### 5个专业化 Agent
1. **项目经理** - 协调者，可以委派任务
2. **市场研究分析师** - 数据收集和分析
3. **技术评估专家** - 技术可行性评审
4. **财务分析师** - 财务建模和ROI计算
5. **报告撰写专家** - 整合所有分析结果

## 核心特性

### 任务链式依赖
```
市场调研 → 技术评估 → 财务分析 → 综合报告
   ↓           ↓           ↓          ↓
 [context] → [context] → [context] → [最终输出]
```

每个后续任务都能访问前面所有任务的输出。

### 角色分工
- 每个 Agent 都有明确的专业领域
- 使用 `allow_delegation` 控制任务委派权限
- 项目经理可以协调其他成员的工作

### 上下文传递
通过 `context` 参数实现任务间的数据流转

## 运行方式

```bash
# 安装依赖
pip install -r requirements.txt

# 配置环境变量 (.env)
OPENAI_API_KEY=your_key

# 运行
python main.py
```

## 输出文件
- `output/comprehensive_market_analysis.md` - 完整的市场分析报告
