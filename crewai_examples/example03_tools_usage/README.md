# 示例3：工具使用

## 概述
这个示例演示了如何为 Agent 配置各种工具来扩展其能力。工具是 Agent 与外部世界交互的桥梁。

## 集成的工具

### 1. **SerperDevTool** (网络搜索)
- 用途：Google 搜索引擎接口
- 场景：获取实时信息、新闻、数据

### 2. **FileReadTool** (文件读取)
- 用途：读取本地文件内容
- 场景：分析现有文档、配置文件

### 3. **DirectoryReadTool** (目录读取)
- 用途：浏览目录结构
- 场景：了解项目结构、查找文件

### 4. **TXTSearchTool** (文本搜索)
- 用途：在文件中搜索特定内容
- 场景：日志分析、代码搜索

### 5. **WebsiteSearchTool** (网站搜索)
- 用途：在特定网站内搜索
- 场景：从官方网站获取信息

## 架构设计

```
┌─────────────────┐     ┌──────────────────┐     ┌─────────────────┐
│  信息研究员      │     │  文档分析专家     │     │  综合分析顾问    │
│                 │     │                  │     │                 │
│ Tools:          │     │ Tools:           │     │ Tools:          │
│ • SerperDev     │ -->  │ • FileRead       │ -->  │ • SerperDev     │
│ • WebsiteSearch │     │ • DirRead        │     │                 │
│                 │     │ • TXTSearch      │     │                 │
└─────────────────┘     └──────────────────┘     └─────────────────┘
       ↓                       ↓                        ↓
   网络研究              本地文档分析              综合报告生成
```

## 核心概念

### 为 Agent 配置工具
```python
agent = Agent(
    ...,
    tools=[SerperDevTool(), FileReadTool()]
)
```

### 工具的选择原则
- **研究员** → 搜索类工具（获取外部信息）
- **分析师** → 文件操作工具（处理已有数据）
- **综合者** → 混合工具（补充验证）

### 工具的优势
- 🚀 扩展 Agent 的能力边界
- 🔗 连接外部数据源
- 💾 处理本地资源
- ⚡ 提高效率和专业性

## 运行说明

### 前置条件
```bash
# 安装依赖
pip install -r requirements.txt

# 环境变量 (.env)
OPENAI_API_KEY=your_key
SERPER_API_KEY=your_serper_key  # 用于搜索功能
```

### 准备测试数据（可选）
```bash
mkdir -p data
# 在 data/ 目录下放置一些文本文件用于测试
```

### 执行
```bash
python main.py
```
